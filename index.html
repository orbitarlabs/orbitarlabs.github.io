A different foundation

More calculation.
Less overhead.

orbitaR is a high-performance electronic structure engine written entirely in Rust. Its goal is not to trade away the physics for speed, but to make the numerical work more efficient and easier to run.

The initial pilots measure time to a common convergence target and peak memory against established electronic-structure codes. Separate numerical checks compare results using identical PAW datasets.

01 / Performance

Same target. Less compute.

Faster convergence. A smaller memory footprint. Early benchmarks against two established electronic-structure engines, at a common accuracy target.

05 / Engineering

Rust is more than
a language choice.

Control of memory, native numerical libraries and shared-memory parallelism make the Rust-native engine a natural fit for iterative electronic-structure calculations.

01 / MEMORYLOBPCG

Allocate once. Reuse.

LOBPCG workspaces retain matrix storage across solves, allocating again only when more capacity is needed.

Ownership · explicit allocation
02 / NUMERICSFFT + LINALG

Native numerical paths.

RustFFT and faer provide native Rust FFT and linear-algebra building blocks for the plane-wave and eigensolver routines.

RustFFT · faer
03 / PARALLELISMRAYON

Parallel by design.

Rayon thread pools distribute independent numerical work inside one process. Thread count is explicit; one tested 1-vs-4-thread case is bit-identical.

Rayon · shared memory
WHY RUST?

Rust's ownership and borrowing rules check memory access at compile time; its concurrency model makes it possible to express safe shared-memory and disjoint work. The checked engine workspace also forbids unsafe_code in its own crates; this is not an audit of all dependencies.

Implementation illustrations, not measured kernel-level traces. Ownership · Concurrency · Rayon.

06 / Getting started

One engine.
Three ways to work.

Use familiar tools for electronic-structure calculations. Start from ASE or a terminal, with an agent-facing MCP integration on the roadmap.

Python · ASE calculator
# A periodic crystal in ASE
from ase.build import bulk
from orbitar.ase import Orbitar

atoms = bulk("Si", "diamond", a=5.43)
atoms.calc = Orbitar(cutoff_ha=10.0, kpoints={"mesh": [2, 2, 2]})
energy = atoms.get_potential_energy()
